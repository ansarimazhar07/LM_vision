# @lm-vision/ui

This package establishes the **shared design system boundary, color tokens, typography scales, and UI constants** for LM-Vision (SIH 2026 Problem Statement 26034).

## Scope in Phase 1

Per Phase 1 specifications, this package sets up the package boundary, design tokens, and status badge mappings. Complete component libraries (React / React Native cross-platform primitives) will be implemented in subsequent phases.
